Why a graph database?

Career paths aren't tables — they're networks. SkillBridge models skills, roles, people, and companies as a connected graph so we can ask questions like "What's the shortest learning path from Java to System Design?" or "Who bridges Backend and ML Engineering through shared skills?" — queries that require painful self-joins in SQL.
